# Changelog

All notable changes to the TickBytes dataset and repository will be documented in this file.

## [1.0.0] - 2026-08-06
### Added
- Initial public release of TickBytes repository.
- Structured documentation: Data Dictionary, Dataset Coverage, Schema, and Naming Conventions.
- Code examples in Python, Pandas, and Polars for parsing, cleaning, and resampling tick data.
- Representative 50-row sample CSV files for all 6 target indices (NIFTY, BANKNIFTY, FINNIFTY, MIDCPNIFTY, SENSEX, BANKEX) covering Spot Index, Futures, and Option chains with Level 2 market depth and Greeks.
